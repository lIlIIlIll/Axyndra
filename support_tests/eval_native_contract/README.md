# Actual Native Eval contract frontend

This support-only package imports the real `AXYNDRA_EVAL_PLUGIN_PACKAGE`,
records operator `plugins/lifecycle.json`, starts the existing Host lifecycle
manager and selects its published namespaced tool. It has no launcher, process
registry, Source/grant constructor, old executor or production dependency.

Each selected workspace/profile has a separate actual Product/Store owner.
The fork test borrows the same original Product and explicitly starts the branch
service after verifying the copied transcript. Complete observed cells retain
their canonical call/error/Receipt and are copied only into a bounded test heap;
the actual consumer then acknowledges the original payload.

Cancellation, a silent startup and the original 32-byte output limit use actual
Service outcomes and cleanup. Unknown is never changed into a fake cell, and a
withdrawn lease never automatically restarts or replays. NUL/missing operator
executable negatives and bare python3 fixed-path positive use the real Host
parser and binding. Frontend capabilities and explicit approvals are test host
inputs, never accepted from a plugin payload.

Current source is uncompiled. All20 original packaged protocol cases, all27
current real interpreter cases with zero skip, original five native Product
cases plus publication, and migrated support configurations/cancellation/CWD/
startup/fork/whole Sandbox still require actual execution. The unrelated old
complete /tools literal is migrated to the fixed actual nineteen-name catalog
and explicit retired-alias absence. Private read/edit/write belong only to the
historical support wrapper; debug/todo/task/program still exist at this source
boundary and are not described as physically retired by this Eval change.
